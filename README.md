# Deksis — лендинг

Один файл `index.html` без сборки: стили и скрипт внутри, внешние зависимости — только шрифты Google Fonts (Unbounded + Manrope).

Открыть локально: просто открыть `index.html` в браузере.
Публикация: GitHub Pages через workflow `.github/workflows/pages.yml` (деплой при пуше в ветку).

## Что внутри
- Интерактивный график «Траектория бизнеса после запуска сайта»: три сценария (только сайт / разовая настройка / постоянное продвижение), 8 этапов работы, скраб по времени мышью или пальцем, переключение сценариев, повтор анимации.
- Параллакс фона, магнитные кнопки, пословное появление заголовка, счётчики.
- Основной цвет `#0058ff`, тёмный фон в стилистике текущего deksis.ru.

## Секции ниже первого экрана
- Бегущая строка услуг (две ленты навстречу, наклон зависит от скорости прокрутки).
- Услуги: карточки с подсветкой под курсором, 3D-наклоном и прорисовкой иконок.
- Кейсы: горизонтальная лента, закреплённая при прокрутке на десктопе; на мобильных — свайп-карусель.
- Процесс: таймлайн, линия которого заполняется по мере прокрутки.
- Цифры с анимированными счётчиками, FAQ-аккордеон, форма заявки с плавающими подписями и конфетти, подвал с большим логотипом.
- Липкая шапка (прячется при прокрутке вниз), полноэкранное мобильное меню, индикатор прогресса, кнопка «наверх», курсор-follower на десктопе.
- Учитывается `prefers-reduced-motion`.

> Кейсы, цифры «О компании» и ответы FAQ — заглушки, замените на реальные данные. Форма пока не отправляет данные на сервер — только показывает состояние успеха.
